# _Basic Bot_ Example

> [!IMPORTANT]
> This is heavily based on [Fluxer.py Template](https://github.com/PerpetualPossum/fluxer-py-template), if you want a quick, easily clonable, ready-to-go setup, check that out!

## Features

- Basic bot object usage
- Bot events
- Bot commands
- Cog (extensions) usage
- Permission checking with commands
- Cog commands (commands within Cog classes)
- Cog listeners (listeners within Cog classes)

## Setup

### Requirements

- Python 3.10 or higher
- A computer

> [!NOTE]
> Though Python 3.10 is supported, version 3.14 is currently (27/03/2026) recommended for it's [current status](https://devguide.python.org/versions/).
